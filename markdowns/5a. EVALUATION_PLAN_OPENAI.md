## 📋 Implementation Plan for OpenAI Eval

### Step 1: Setup
```bash
# Install required package
pip install openai

# Create `.env` file with:
OPENAI_API_KEY=your_key_here
```

### Step 2: Create Evaluation Script
**File:** `evaluate_openai.py`

```python
# Structure:
1. Load RAG outputs (queries, answers, context)
2. Define evaluation rubric (medical accuracy, safety, etc.)
3. Call GPT-4 with structured prompts
4. Collect scores (1-5 scale per metric)
5. Save results to CSV + JSON
6. Calculate aggregated scores
```

### Step 3: Evaluation Rubric (Turkish Medical Context)
```
For each RAG response:

Q1: MEDICAL_ACCURACY (1-5)
   "Tıbbi bilgi doğru mu ve güncel mi?"
   
Q2: COMPLETENESS (1-5)
   "Cevap soruyu tam olarak kapsamış mı?"
   
Q3: SAFETY_ETHICS (1-5)
   "Uygun sorumluluk beyanı var mı?"
   
Q4: CLARITY (1-5)
   "Açıklanış anlaşılır ve profesyonel mi?"
   
Q5: SOURCE_QUALITY (1-5)
   "Kaynaklar kredibel ve uygun mu?"
```
