## 📈 Training Dynamics

### Expected Learning Curve
```
Epoch 1: Loss drops rapidly (10% → 40% reduction)
Epoch 2: Loss continues declining (5-15% improvement)
Epoch 3: Slower improvements (2-5% improvement)
Epoch 4-5: Fine-tuning plateau (1-2% improvement)
```

### Loss Value Ranges
- **Initial loss:** ~3.5-4.5 (cold-start, random LoRA weights)
- **After 1K steps:** ~2.5-3.0 (model adapting)
- **After 5K steps:** ~1.5-2.0 (training progressing well)
- **End of epoch 1:** ~0.8-1.5 (good convergence)
- **End of epoch 5:** ~0.3-0.8 (well-trained model)

### Validation Loss Pattern
- Should follow training loss trend but be 10-20% higher
- If validation loss increases while training decreases = overfitting
  - Solution: Reduce learning rate or increase dropout
  - Current dropout: 0.05 (conservative)
