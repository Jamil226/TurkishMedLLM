## Fast Commands

### Monitor Training
```bash
# Real-time monitoring (recommended)
bash monitor_training.sh

# Quick status check
nvidia-smi  # GPU usage
tail qlora_training.log  # Recent logs
ls -lh qlora_checkpoints/  # Checkpoint sizes
```

### Check Progress
```bash
# Watch training loss in real-time
watch -n 5 'tail -20 qlora_training.log | grep -i loss'

# Monitor GPU memory
watch -n 2 nvidia-smi

# Count saved epochs
find qlora_checkpoints -name "epoch_*" -type d | wc -l
```

### If Training Stops
```bash
# Resume from latest checkpoint
python finetune_qlora.py --resume_from_checkpoint qlora_checkpoints/epoch_latest

# Check error logs
tail -50 qlora_training.log
```
