## 🎯 3 Evaluation Methods

### Method 1: Local Qwen3 Evaluation
- **Tool**: `evaluate_openai.py` (modified to use local Qwen3:8B)
- **Model**: Qwen3:8B via Ollama (FREE)
- **Metrics**:
  - Medical Accuracy (Tıbbi Doğruluk)
  - Completeness (Bütünlük)
  - Safety & Ethics (Güvenlik & Etik)
  - Clarity (Netlik)
  - Source Quality (Kaynak Kalitesi)
- **Output**: CSV with scores 1-5 for each metric

### Method 2: DeepEval Metrics
- **Tool**: `evaluate_rag.py` (DeepEval section)
- **Metrics**:
  - Answer Relevancy
  - Faithfulness
  - Additional DeepEval metrics
- **Output**: CSV with evaluation scores

### Method 3: RAGAS Metrics
- **Tool**: `evaluate_rag.py` (RAGAS section)
- **Metrics**:
  - Faithfulness (response grounded in context?)
  - Answer Relevancy (response answers the question?)
  - Context Recall (relevant context retrieved?)
  - Context Precision (retrieved context relevant?)
- **Output**: CSV with RAGAS scores
