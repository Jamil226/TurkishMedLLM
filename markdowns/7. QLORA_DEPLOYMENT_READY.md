## Troubleshooting Reference

### If OOM (Out of Memory)
```bash
# Reduce batch size in finetune_qlora.py:
per_device_train_batch_size: int = 4  # from 8

# Reduce sequence length:
max_seq_length: int = 1024  # from 2048

# Restart training
python3 finetune_qlora.py
```

### If GPU Utilization Low (<50%)
```bash
# Check background processes
ps aux | grep -E "ollama|python"

# Kill Ollama if interfering
killall ollama

# Check CPU usage
htop
```

### If Training Crashes
```bash
# Resume from last checkpoint (automatic)
python3 finetune_qlora.py

# All checkpoints are saved, training continues from last

# Check logs
tail -100 logs/events.out.tfevents.*
```

### If Model Loading Fails
```bash
# Pre-download Qwen model
python3 << 'EOF'
from transformers import AutoTokenizer, AutoModelForCausalLM
tokenizer = AutoTokenizer.from_pretrained("Qwen/Qwen2-7B")
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen2-7B")
EOF

# Retry training
python3 finetune_qlora.py
```
