# Libraries and Dependencies Reference

This document maps out the core library ecosystem, dependencies, and execution contexts used throughout the **TurkishMedLLM** pipeline.

---

## 📦 Core Dependencies Overview

The framework relies on a modular set of dependencies spanning data manipulation, vector search, LLM orchestration, evaluation, and interactive interfaces.

### 1. Data Processing & Tabular Loading
These packages handle high-speed reading, parsing, and ingestion of massive clinical datasets (e.g., Zenodo Parquet files).
- **`pandas`**: Primary data manipulation, deduplication, and schema standardizing engine.
- **`pyarrow` & `fastparquet`**: High-performance backend engine for reading Parquet formats with low memory footprints.

### 2. LangChain Orchestration Suite
The operational backbone of our Retrieval-Augmented Generation (RAG) pipeline.
- **`langchain` & `langchain-core`**: Defines the modular interface for prompt templates, chain composition, output parsers, and custom model wrappers.
- **`langchain-text-splitters`**: Powers the dynamic `RecursiveCharacterTextSplitter` to parse medical papers into overlapping chunks based on logical sentence boundaries.
- **`langchain-ollama`**: Standard interface connecting LangChain directly to the local Ollama daemon for chat inference and embedding models.
- **`langchain-chroma`**: Seamless integration layer managing local vector stores through ChromaDB.

### 3. Vector Database Backends
- **`chromadb`**: Fast, lightweight, persistent vector storage directory executing cosine similarity checks over high-dimensional embeddings (`bge-m3:latest`).

### 4. Automated LLM Evaluation
- **`ragas`**: Benchmarks RAG quality metrics including faithfulness, context precision, answer relevancy, and context recall.
- **`deepeval`**: Framework providing semantic similarity, relevancy scoring, and unit testing pipelines for prompt alignment.

### 5. Web Interface & UI
- **`streamlit`**: A beautiful front-end python framework rendering our interactive clinic chatbot, complete with chat history export features and real-time citation views.

### 6. Pipeline Utilities
- **`tqdm`**: Renders dynamic progress bars tracking ingestion, transformation, and vector store batch uploads.
- **`beautifulsoup4`**: Extracts text from raw crawled clinical data by removing HTML markup.
- **`python-dotenv`**: Automatically loads runtime and baseline parameters from a local `.env` configuration file.

## 🛠️ Installation & Setup

To install all workspace requirements:

```bash
# Activate your local python environment
source venv/bin/activate

# Install locked dependencies
pip install -r requirements.txt
```

To verify active installations:

```bash
pip list | grep -E "langchain|chroma|ragas|deepeval|streamlit"
```
