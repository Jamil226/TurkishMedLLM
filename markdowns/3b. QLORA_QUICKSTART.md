## What is QLoRA?

QLoRA is a memory-efficient fine-tuning method that combines:
- **4-bit Quantization:** Reduces model size by 75% (16GB → 4GB)
- **LoRA Adapters:** Adds trainable layers (50MB total) without modifying base weights
- **Result:** Train large models on consumer GPUs with minimal memory

**Benefits for your setup:**
- ✅ Uses only ~20GB VRAM (safe on RTX 5000 with 64GB)
- ✅ Trains 3-5x faster than full fine-tuning
- ✅ Quality loss: <3% vs full fine-tuning
- ✅ Checkpoints: 50MB each (vs 16GB for full model)

### What's Normal

✅ **Normal Behavior:**
- Training loss: Decreases steadily, then plateaus
- Validation loss: Follows training loss
- GPU memory: Stable ~18-22GB
- GPU util: 95%+
- Speed: 50-100 tokens/sec

⚠️ **Warning Signs:**
- Training loss: Increases or spikes suddenly
- GPU memory: Growing unbounded
- GPU util: <50% (possible issue)
- Speed: <20 tokens/sec (check background processes)

❌ **Error Cases:**
- OOM error: Reduce batch size to 4
- CUDA error: Restart Ollama or system
- Data error: Check JSON format of training data

## Troubleshooting

### Problem: OOM (Out of Memory)
```bash
# Solution 1: Reduce batch size
# Edit finetune_qlora.py, change:
per_device_train_batch_size: int = 4  # from 8

# Solution 2: Reduce sequence length
max_seq_length: int = 1024  # from 2048

# Solution 3: Reduce gradient accumulation
gradient_accumulation_steps: int = 2  # from 4
```

### Problem: CUDA Out of Memory During Setup
```bash
# Solution: Clear GPU cache
python3 << 'EOF'
import torch
torch.cuda.empty_cache()
print("GPU cache cleared")
EOF

# Or restart system
```

### Problem: Model Loading Fails
```bash
# Check HuggingFace token
cat ~/.cache/huggingface/token

# Or download manually
huggingface-cli download Qwen/Qwen2-7B --local-dir ./models/qwen2-7b
```

### Problem: Training is Slow (<20 tokens/sec)
```bash
# Check if Ollama is running (consuming GPU)
ps aux | grep ollama

# Kill Ollama to free GPU
killall ollama

# Or check CPU usage
htop | grep python
```

### Problem: Checkpoint Not Saving
```bash
# Check directory permissions
ls -ld qlora_checkpoints/

# Fix if needed
chmod -R 755 qlora_checkpoints/

# Restart training
python3 finetune_qlora.py
```
