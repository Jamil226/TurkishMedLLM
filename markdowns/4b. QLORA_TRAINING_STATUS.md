## Checkpoint Structure

Checkpoints will be saved to `qlora_checkpoints/`:

```
qlora_checkpoints/
├── checkpoint-500/          # Early checkpoint during epoch 1
├── checkpoint-1000/         # Halfway point
├── epoch_1/                 # End of epoch 1
│   ├── adapter_config.json
│   ├── adapter_model.bin    # ~50MB LoRA weights
│   ├── training_args.bin
│   └── trainer_state.json
├── epoch_2/ through epoch_5/
└── final_model/             # Latest checkpoint after training
```

Each epoch saves:
- LoRA adapter weights (~50MB)
- Trainer state and arguments
- Training configuration

**Total Size:** ~250MB-300MB (all 5 epochs)

## Troubleshooting During Training

### Issue: Training stuck during model download
**Solution:** 
- Check internet connection
- Delete `~/.cache/huggingface/` to clear cache
- Restart: The script will resume from checkpoint

### Issue: Out of Memory (OOM) error
**Solution:**
- This shouldn't happen with RTX 5000 (33.8GB available)
- If it does, reduce batch size: `QLORA_BATCH_SIZE = 4` in `src/config.py`

### Issue: GPU not being used
**Solution:**
```bash
nvidia-smi  # Verify GPU is visible
# If not visible, ensure CUDA_VISIBLE_DEVICES is set correctly
```

### Issue: Training is very slow
**Expected:** Each epoch takes 2.5-3 hours with full throughput  
**If slower:** Check GPU utilization (should be 90%+ after loading phase)
